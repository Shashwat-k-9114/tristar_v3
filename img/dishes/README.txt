DISH PHOTOS
Run  python download_dish_photos.py  (from the folder containing index.html).
It downloads free-licensed photos into this folder, writes photos.js and CREDITS.txt, and the menu shows them automatically.
To use your own photo for a dish: save it here as <dish-name>.jpg (lowercase, hyphens: mutton-biryani.jpg) and add the same name to photos.js.
